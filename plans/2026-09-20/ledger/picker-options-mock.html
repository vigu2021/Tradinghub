Three ways to pick a group

Same existing groups in each: Banks, Binance, Home safe, Savings, Vanguard. Try picking one, and try adding a new one such as "Trading 212". The grey box under each shows the value the form would send. On a phone, the first one opens the phone's own picker.

1 · Recommended for now

Dropdown + "New…"

Native select with an extra last option that reveals a text box.

How you file it, like Binance, Savings or Home safe

  • Keyboard, screen readers and phone pickers work for free
  • Can't misspell an existing group
  • Little code, no library
  • A new group takes two steps
  • Long lists mean scrolling
2 · Smoothest, hardest

Type to search, "Create…"

A combobox, like Notion or Linear: typing filters, and an unmatched name offers to create it.

    How you file it, like Binance, Savings or Home safe

    • One box: type, pick or create
    • Stays quick with long lists
    • Accessible version is hard to hand-build (arrow keys, announcements, focus)
    • Usually means adding a library
    • On phones the list can fight the keyboard for space
    3 · Simplest, weakest

    Text box with suggestions

    A native <datalist>: a plain text box the browser offers suggestions for.

    How you file it, like Binance, Savings or Home safe

    • Almost no code
    • New groups need no extra step
    • Nothing stops "Binnace" becoming its own group
    • Suggestions look different in every browser, and are easy to miss on phones
